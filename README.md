# kanji-renshu

**漢字れんしゅう 〜中学入試対策〜**

中学入試によく出る漢字を、読み方・書き順・熟語・意味からまとめて学べるアプリです。
`index.html` をブラウザで開くだけで動きます（ビルド不要・依存なし）。

## iPad・スマホで使う（GitHub Pages）

公開URL：**https://4r4ki.github.io/kanji-renshu/**

初回だけ GitHub で設定が必要です。

1. リポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source を「Deploy from a branch」にする
3. Branch を **`main`**、フォルダを **`/ (root)`** にして **Save**
4. 1〜2分待つと上のURLで開けるようになる

iPad の Safari で開き、共有ボタン →「ホーム画面に追加」を選ぶと、アプリのようにホーム画面から起動できます。
学習記録はその iPad のブラウザに保存されます（ほかの端末とは共有されません）。

## できること

- **漢字じてん**：270字を一覧表示。漢字・読み・熟語で検索でき、レベル（★基本／★★標準／★★★発展）でしぼりこめる
  - 書き順アニメーション（再生・1画ずつ・画数番号の表示）
  - 画数・音読み・訓読み（送りがな付き）・意味
  - 熟語・ことば（読み・意味・例文）
  - 形の似た漢字（まちがえやすい字）
- **書き順れんしゅう**：指・ペン・マウスでなぞって書くと1画ずつ判定
  - 書き順のまちがい（「それは7画目」）、書く向きの逆を教えてくれる
  - お手本を「うすく表示」／「かくす」に切りかえ可能。2回まちがえるとヒントを表示
- **クイズ**（5／10／20問）
  - 読みクイズ：例文の――線のことばの読み
  - 書き取りクイズ：カタカナを漢字に。同じ読みの漢字・形の似た漢字がまちがいの選択肢に出る。「書いて自己採点」モードあり
  - 意味クイズ：熟語の意味をえらぶ
  - 書き順・画数クイズ：「赤いところは何画目？」「総画数は？」
  - 四字熟語：□に入る漢字・意味から四字熟語をえらぶ（48語）
  - 対義語・類義語（71組）
  - 同音異義語・同訓異字（対象／対照／対称、計る／測る／量る など 46組）
  - 難読・特別な読み：境内・建立・名残・雪崩 など（42語）
  - 送りがな：承る？ 承わる？ 正しい送りがなをえらぶ（32問）
  - 誤字訂正：文の中のまちがった漢字をタップしてさがす（38問）
  - 熟語の構成：似た意味・反対の意味・修飾・「〜を／〜に」・打ち消し（63語）
  - ミックステスト：全種類をまぜて出題
  - 各漢字のページから「この漢字のクイズ」
- **難関中心モード**（出題レベル「★★★ 難関中心」・初期設定）：全範囲から、難しい問題を7割以上の割合で優先して出題
- **にがて復習**：まちがえた問題がたまり、2回続けて正解すると消える
- 学習記録（正答率・漢字ごとの習熟度）はブラウザに保存されます

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面とスタイル |
| `js/app.js` | アプリ本体（画面・クイズ・書き順判定） |
| `js/data.js` | 漢字データ（読み・意味・熟語・例文） |
| `js/data-extra.js` | 四字熟語・対義語・類義語・同音異義語・同訓異字・形の似た漢字 |
| `js/strokes.js` | 書き順データ（KanjiVG から生成） |
| `tools/build-strokes.py` | `js/strokes.js` を作るスクリプト |

### 漢字をふやすには

1. `js/data.js` に `K('漢', レベル, '音読み', '訓読み', '意味', [熟語...])` を追加
2. 書き順データを作り直す

```sh
git clone --depth 1 https://github.com/KanjiVG/kanjivg /tmp/kanjivg
python3 tools/build-strokes.py /tmp/kanjivg
```
